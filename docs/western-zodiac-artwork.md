# Western zodiac library artwork

The 12 `public/artwork/western-*.webp` cutouts were generated with the built-in image tool for the library compatibility pages. Source outputs are preserved in this Codex task's `generated_images` folder. The delivered WebP files retain transparency and are resized to 640 px wide for the 220 px desktop and 132 px mobile placements.

Shared prompt: “Original archival specimen sculpture rendered like an antique black-and-white engraving and hard-lit still-life; dense stippled grain, graphite/silver tones, high silhouette clarity at 150px. Match an existing monochrome abacus, armillary sphere, and Chinese zodiac figurine illustration set. Genuine transparent background and clean cutout edges. No floor, shadow plane, circle, border, text, glyph, watermark, extra objects, or gold color.”

Subjects: Aries ram; Taurus bull; Gemini twins; Cancer crab; Leo lion; Virgo maiden with wheat; Libra balance scales; Scorpio scorpion; Sagittarius centaur archer; Capricorn sea-goat; Aquarius water bearer; Pisces two linked fish.

The library uses the entry slug to select exact images for each Western sign pair, including same-sign pairs. The existing armillary image remains on Western astrology hubs and calculator pages.
